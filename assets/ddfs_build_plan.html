Implement continuous-time 2-DoF robot arm dynamics.

Class: RobotArm2DoF __init__(self, m1, m2, l1, l2, lc1, lc2, I1, I2, b1, b2, g=9.81) mass_matrix(self, q) → (2,2) M(q) coriolis_matrix(self, q, qdot) → (2,2) C(q,q̇) gravity_vector(self, q) → (2,) G(q) dynamics(self, x, u) → (4,) ẋ = f(x,u)
Key equations:
• a = I₁ + I₂ + m₁l²c₁ + m₂(l²₁ + l²c₂)
• b = m₂l₁lc₂
• d = I₂ + m₂l²c₂
• M(q) = [[a+2b·cos(q₂), d+b·cos(q₂)], [d+b·cos(q₂), d]]

Step 5.2 data_driven/beta_computation.py
data_driven/data_collection.py, linearization/lipschitz.py

Compute disturbance energy bound β_i (Eq. 16).

compute_beta(eta_log, xi_log, data_window, k_i, C, gamma, L_r) → β_i
def compute_beta(eta_log, xi_log, data_window, k_i, C, gamma, L_r): beta = 0.0 for k in data_window: z = np.concatenate([eta_log[k], xi_log[k]]) norm_z = np.linalg.norm(z) term = C * abs(k - k_i) * norm_z + gamma + L_r * norm_z**2 beta += term**2 return beta

Step 6.3 synthesis/sdp_solver.py
synthesis/lmi_matrices.py, synthesis/ellipsoid_bounds.py

Main SDP solver (Eq. 22).

solve_funnel_sdp(H, H_plus, Xi, beta, P_min, R_max, alpha, C, T_tilde, P_prev=None, mu=1.02) → (P_opt, K_opt, success)
# SDP structure: # maximize log det(P) # subject to P ≻ 0 # λ₁ ≥ 0, λ₂ ≥ 0, ν > 0 # S(P, L, ν) - λ₁·Ñ₁ - λ₂·Ñ₂ ≽ 0 # P ≽ P_min # [R_max, L; L^T, P] ≽ 0 # P ≼ μ·P_prev (if not first segment)

🐛 Debugging Guide

Common Issues & Solutions

Issue: SDP returns infeasible
Check:
  • Is rank([H; Xi]) = 6? If not, add more excitation.
  • Is β too large? Reduce deviations or increase α.
  • Is P_min too restrictive? Check nominal is far from bounds.
Issue: LMI matrix dimensions wrong
Check:
  • Block indices: [0, 4, 8, 10, 14, 16, 20]
  • S is (20, 20), N1_tilde is (20, 20), N2_tilde is (20, 20)
  • H is (4, L), Xi is (2, L) where L = 60
Issue: Trajectory diverges
Check:
  • Is initial K0 stabilizing? Test on linearized twin.
  • Are states clipped to constraints?
  • Is plant starting too far from nominal?
Issue: Lipschitz estimates way off from paper
Check:
  • Are you using discrete-time Jacobians (not continuous)?
  • Is the finite difference step size appropriate (1e-6)?
  • Are plant/twin parameters exactly as in Table I?
